# Moses Gana

I go by **Noxus**. UK based. I build small, honest tools out of the things I already care about: sport, games, anime, music, tech, fitness, sneakers. Almost everything here started as a problem I hit myself and got tired of.

## Shipped and live

**[Evenweek](https://gmanthenoxus.github.io/shift-planner)**
Tells shift workers how many hours a week they actually need to work, after tax. Two questions, about a minute, then the number. Nine country tax models plus a custom rate. Nothing leaves your browser: no account, no server, no analytics, zero network requests.

**[Sporelo](https://gmanthenoxus.github.io/sporelo-app/)**
The permanent record for grassroots sport. One person scores a match on one phone with no signal and no account, and gets back a box score and a match report that survive the walk home. Score is derived from an append-only event log, never stored as counters. Basketball first, the engine is sport-agnostic. 194 tests. R1 is live, R2 (venue and player records) is in planning.
Sporelo is its own brand, structurally independent from Noxus. I built it, but it doesn't sit under my personal brand and it never shares a logo or a channel with it.

## How I build

I don't freestyle builds. Every project gets:

- scope frozen before the first line of code
- architecture written before the first file
- an adversarial QA pass before anything deploys
- a parking lot where my own good mid-build ideas go to wait instead of derailing the thing I'm supposed to be finishing
- a handover doc at the end of every session, because the next session has no memory and the notes are the only memory the work has

Heavy for a solo builder. It's also the only reason anything gets finished.

## The part I'd rather be honest about

I built the same idea five times before this one. Every attempt independently decided the match record was the first thing to build, and every attempt then died from what I bolted on afterwards. Sporelo is the clean restart that builds only that first thing and then stops.

I also ran a public "49 projects" scoreboard on this profile: phase bars, target dates and counts, all published before any of the work existed. The counts contradicted each other page to page, the bars never left zero, and the first thing it logged as a finished project was the portfolio itself. It's gone. The rule that replaced it: never publish a number I won't keep true.
